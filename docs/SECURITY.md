# BLYc Security Policy & Architecture

## 1. Package & Dependency Integrity Policy
- **Official Registries Only:** All Node.js packages are resolved strictly from the official npm registry (`https://registry.npmjs.org/`). Python packages are resolved from the official PyPI repository (`https://pypi.org/`).
- **No Unvetted or Third-Party Scripts:** Arbitrary third-party build scripts are blocked (`--ignore-scripts` enabled during build pipelines). Prebuilt native binaries are checked for signature integrity and official maintainer source.
- **Strict Scope of Packages:** Only standard, widely adopted, actively maintained enterprise libraries are permitted (Express, Helmet, Mongoose, Zod, React, Recharts, Lucide, Pandas, NumPy, FastAPI). No unverified utility libraries or malware vectors are accepted.

## 2. Authentication & Authorization Guardrails
- **Password Protection:** Cryptographic password hashing using Argon2id with secure salt generation.
- **Session Protection:** JSON Web Tokens (JWT) stored in HTTP-Only, Secure, SameSite cookies to mitigate XSS-based token theft.
- **Tenant Isolation:** Every incoming API request validates ownership (`user_id === project.owner_id`). No multi-tenant data leaks or cross-project data leakage.

## 3. Sandboxed Analytics & Safe Formula Parsing
- **Prohibition of `eval()` & `exec()`:** The custom formula calculator must parse user mathematical expressions through strict Abstract Syntax Trees (AST). Arbitrary JavaScript or Python evaluation is strictly forbidden.
- **Loopback Internal Shielding:** Tier 3 (Python Analytics Engine) listens exclusively on internal loopback (`127.0.0.1:8001`), shielded by firewall and reverse proxy from any external internet exposure. All requests must route through Tier 2 with validated session authorization.

## 4. AI Interpretation Layer Security (Tier 5)
- **Model Lock:** Pinned strictly to Groq `openai/gpt-oss-20b`.
- **Zero Raw Data Ingestion:** The AI model never receives full spreadsheets, passwords, or customer personal identities. Only aggregated, verified statistical figures generated by Python are sent to explain business insights.
- **Prompt Injection Defense:** Dataset cell contents are treated as untrusted data inputs, explicitly quarantined from system instruction contexts.
